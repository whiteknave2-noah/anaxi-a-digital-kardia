## 0. How to read the catalog

Each production capability records five things:

1. **Affordance** — what the system actually makes possible.
2. **Authority / provenance** — who may cause it, what record is authoritative, and what scope applies.
3. **Acceptance basis** — how the current claim was established.
4. **Important non-claims** — what the capability does *not* prove or imply.
5. **Status** — current production disposition.

Status vocabulary:

- **ESTABLISHED LIVE** — real production use established the end-to-end path.
- **ESTABLISHED / SYSTEM** — production mechanism and cross-cutting evidence establish the capability; not every property requires a fresh subject action.
- **OWNER ACCEPTED / OFFLINE** — accepted on production-shaped/offline evidence where manufacturing a live occasion would be inappropriate.
- **OPTIONAL USE NOT OBSERVED** — mechanism is available, but natural subject-originated use was not observed during the final acceptance window.
- **WITHDRAWN** — the historical intended capability did not pass and is not represented as available in the current release.
- **NOT_ESTABLISHED** — the positive claim is unsupported.

The catalog follows ANAXI's completion rule:

> **A mechanism existing in code is not enough. A represented capability must be meaningfully usable through the ordinary production path.**

# PART XI — CROSS-CUTTING NON-CLAIMS

No individual capability in this catalog should be read as proving:

- consciousness;
- sentience;
- personhood;
- human-like phenomenology;
- trust;
- friendship;
- affection;
- comprehension merely because content was delivered;
- memory merely because material was retrieved;
- hearing merely because audio was measured;
- rest merely because Sleep consolidation completed;
- or a new individual merely because the inference model changes.

The catalog describes production affordances and engineering evidence.

It intentionally stops there.

# Closing principle

A completed ANAXI capability should answer a concrete question truthfully:

> **What can the subject actually do here, who has authority, what happened, and what must we refrain from claiming?**

If those four answers are not clear, the capability is not adequately described.
